# Spotlight demo video: script and storyboard

Target: 1:55 to 2:00, 1920x1080, 30 fps. Submission rule: 2 minutes or less, showing the app working end to end with real Buffer API calls.

Principles: hook in the first 5 seconds; real product footage for everything the product does; one idea per scene; the brand system from the landing page (mist #EFF3EE, ink #14211F, sun #FFCB1F, Schibsted Grotesk, viewfinder logo); captions on screen for every narration line (many people watch muted).
